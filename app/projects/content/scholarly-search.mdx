A scholarly article search application built with Python, Flask and Elasticsearch,
running a scalable indexing pipeline over 50,000+ articles with keyword-weighted
ranking and faceted filters.

## Beyond search

User authentication, input validation, structured query logging and integration
test coverage are unified into the same pipeline, so deployments stay accurate,
secure and repeatable rather than depending on manual checks.
