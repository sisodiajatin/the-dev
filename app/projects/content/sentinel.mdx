A real-time DDoS threat visualisation platform built with React 18, TypeScript and
D3.js, rendering live attack events on 3D and 2D geospatial maps as they stream in
from the backend.

## How it works

A Vercel serverless Node.js backend aggregates and serves real-time threat feeds
from two intelligence sources — AbuseIPDB and AlienVault OTX — keeping event
delivery to the frontend low-latency.

Attack events are visualised with D3.js and Recharts across time-series trends,
geographic hotspot analysis and threat scoring. IndexedDB stores events locally so
an attack sequence can be replayed offline.
